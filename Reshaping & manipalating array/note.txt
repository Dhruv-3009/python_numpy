# Reshaping and Manipulating Arrays in NumPy

## 1. Reshaping an Array

**Reshaping** means changing the shape of an array without changing its elements.

### Syntax

```python
array.reshape(rows, columns)
```

### Example

```python
import numpy as np

arr = np.array([1, 2, 3, 4, 5, 6])

new_arr = arr.reshape(2, 3)

print(new_arr)
```

**Output:**

```text
[[1 2 3]
 [4 5 6]]
```

Here:

```text
Original shape → (6,)
New shape      → (2, 3)
```

The total number of elements must remain the same:

```text
2 × 3 = 6
```

---

# 2. Checking the Shape

The `shape` attribute tells us the dimensions of an array.

```python
arr = np.array([[1, 2, 3], [4, 5, 6]])

print(arr.shape)
```

**Output:**

```text
(2, 3)
```

This means:

```text
2 rows
3 columns
```

---

# 3. Flattening an Array

**Flattening** converts a multidimensional array into a one-dimensional array.

### Using `flatten()`

```python
arr = np.array([[1, 2, 3], [4, 5, 6]])

result = arr.flatten()

print(result)
```

**Output:**

```text
[1 2 3 4 5 6]
```

---

# 4. Ravel

`ravel()` also converts an array into one dimension.

```python
arr = np.array([[1, 2, 3], [4, 5, 6]])

print(arr.ravel())
```

**Output:**

```text
[1 2 3 4 5 6]
```

---

# 5. Transpose

**Transpose** changes rows into columns and columns into rows.

### Example

```python
arr = np.array([[1, 2, 3],
                [4, 5, 6]])

print(arr.T)
```

**Output:**

```text
[[1 4]
 [2 5]
 [3 6]]
```

Shape changes:

```text
(2, 3) → (3, 2)
```

---

# 6. Resizing an Array

`resize()` changes the size of an array.

```python
arr = np.array([1, 2, 3, 4])

arr.resize(2, 3)

print(arr)
```

**Output:**

```text
[[1 2 3]
 [4 0 0]]
```

If more elements are required, NumPy fills the extra positions with `0`.

---

# 7. Adding Elements

### `append()`

`append()` is used to add elements to an array.

```python
arr = np.array([1, 2, 3])

new_arr = np.append(arr, 4)

print(new_arr)
```

**Output:**

```text
[1 2 3 4]
```

---

# 8. Inserting Elements

`insert()` adds an element at a specific index.

```python
arr = np.array([1, 2, 4, 5])

new_arr = np.insert(arr, 2, 3)

print(new_arr)
```

**Output:**

```text
[1 2 3 4 5]
```

Here:

```text
index = 2
value = 3
```

---

# 9. Deleting Elements

`delete()` removes an element from an array.

```python
arr = np.array([1, 2, 3, 4, 5])

new_arr = np.delete(arr, 2)

print(new_arr)
```

**Output:**

```text
[1 2 4 5]
```

Here, the element at index `2` (`3`) is removed.

---

# 10. Concatenating Arrays

**Concatenation** means joining two or more arrays.

```python
arr1 = np.array([1, 2, 3])
arr2 = np.array([4, 5, 6])

result = np.concatenate((arr1, arr2))

print(result)
```

**Output:**

```text
[1 2 3 4 5 6]
```

---

# 11. Stacking Arrays

## Vertical Stack

`vstack()` joins arrays row-wise.

```python
arr1 = np.array([1, 2, 3])
arr2 = np.array([4, 5, 6])

print(np.vstack((arr1, arr2)))
```

**Output:**

```text
[[1 2 3]
 [4 5 6]]
```

## Horizontal Stack

`hstack()` joins arrays column-wise.

```python
print(np.hstack((arr1, arr2)))
```

**Output:**

```text
[1 2 3 4 5 6]
```

---

# Quick Revision

| Operation        | Function / Method | Purpose               |
| ---------------- | ----------------- | --------------------- |
| Reshape          | `reshape()`       | Change array shape    |
| Shape            | `.shape`          | Check dimensions      |
| Flatten          | `flatten()`       | Convert to 1D         |
| Ravel            | `ravel()`         | Convert to 1D         |
| Transpose        | `.T`              | Rows ↔ Columns        |
| Resize           | `resize()`        | Change array size     |
| Add              | `append()`        | Add elements          |
| Insert           | `insert()`        | Add at specific index |
| Delete           | `delete()`        | Remove elements       |
| Concatenate      | `concatenate()`   | Join arrays           |
| Vertical stack   | `vstack()`        | Stack rows            |
| Horizontal stack | `hstack()`        | Join horizontally     |

## Easy Way to Remember

```text
Reshape      → Change shape
Flatten      → Make 1D
Transpose    → Rows ↔ Columns
Append       → Add at end
Insert       → Add at position
Delete       → Remove
Concatenate  → Join
Stack        → Combine arrays
```
